Constructor Internal Process Flow

Object Creation

Example: obj1 = Example("Ravi")

A new object of the class is created in memory.

⬇️
Constructor Trigger

__init__(self, name)

Constructor is automatically called after the object is created.

⬇️
Self Reference

self points to the memory address of the new object.

It ensures the object’s properties and methods are correctly initialized.

⬇️
Memory Assignment

The memory location of the object is stored in self.

Example: id(self) = 1400

⬇️
Property Initialization

Constructor initializes properties like self.name = "Ravi".

These properties are now specific to the object.

⬇️
Function Call with Object Properties

When a method is called, self passes the object’s values.

Example: obj1.display() uses self.name as "Ravi".

Flow Summary:

  • Object Creation: A new instance of the class is created in memory.
  • Constructor Trigger: The __init__ method is automatically invoked.
  • Self Reference: The new object’s memory reference is passed to self.
  • Memory Assignment: self holds the unique memory address of the object.
  • Property Initialization: Properties are set using the constructor’s parameters.
  • Function Interaction: Methods can access and use the object’s properties through self.
